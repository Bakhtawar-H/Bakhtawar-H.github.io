# Bakhtawar Halepoto — portfolio

A static portfolio site. No build step; it runs as-is on GitHub Pages.

## Publish on GitHub Pages

1. Create a new public repository on GitHub named **Bakhtawar-H.github.io** (use your exact username). The site will then live at `https://bakhtawar-h.github.io`.
2. Upload everything in this folder to the repository: `index.html`, `.nojekyll`, the `assets` folder and the `work` folder. In GitHub Desktop, copy the files into the cloned repository folder, commit, and push.
3. In the repository, open **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute or two, the site is live at the address shown on that page.

## Editing

- Home page: `index.html`
- Project pages: `work/*.html`
- Styles: `assets/style.css`
- Images and PDFs: `assets/img` and `assets/pdf`
