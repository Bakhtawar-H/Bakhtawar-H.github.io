Beginner's tutorial: your first website on GitHub

A step-by-step guide for Mac users with no coding background. It walks through installing VS Code and the Markdown All in One and Peacock extensions, setting up GitHub Desktop, creating a repository with an index.html file, committing and pushing changes, publishing with GitHub Pages, and writing a README.
